A full-stack AI chatbot built with FastAPI + LangChain on the backend and React on the frontend. Bruno runs entirely locally using Ollama with the LLaMA 3 model — no cloud API keys required.
Features:

a) Conversational AI with persistent chat history
b) Sleek dark glassmorphism UI with smooth animations
c) Powered by LLaMA 3 via Ollama — runs 100% locally, no API keys needed
d) Clear conversation button to reset context
e) Input validation and error handling on both frontend and backend

Tech Stack
LayerTechnologyFrontend:React, Vite
Backend: FastAPI, Python 
AI / LLM :LangChain, Ollama (LLaMA 3)
Styling: CSS-in-JS
